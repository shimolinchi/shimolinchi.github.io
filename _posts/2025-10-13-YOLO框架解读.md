> 最近实习的时候用到yolo去识别物体进行抓取，于是简单将yolo用法和框架学习了一下

# 简单用法

yolo提供的用法主要有：

+ detect，即检测模型，将物体用矩形框起来
+ segment，即分割模型，可以分割出物体的边缘
+ classify，分类模型，用于图像分类
+ pose，姿态估计，可用于关键点检测

还有一些不太常用的，不做介绍。
简单使用的话就是先训练模型（也可以不用训练，直接用官方提供的模型）

```
yolo detect train model=path/to/your/model.pt epoches=500 data=data.yaml batch=16 imgsz=640 device=0
```

这些参数详细参考[官方文档](https://docs.ultralytics.com/zh/modes/train/#resuming-interrupted-trainings)

训练完了模型就可以进行使用，简单的示例代码如下：

```python
import cv2
from ultralytics import YOLO

# 1. 加载YOLO模型
model = YOLO("best.pt")

# 2. 读取图片
img = cv2.imread("test.jpg")

# 3. 推理（目标检测）
results = model(img)

# 4. 在图像上绘制检测结果
annotated_img = results[0].plot()

# 5. 显示结果
cv2.imshow("YOLO Detection", annotated_img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

# YOLO v5

![](https://raw.githubusercontent.com/shimolinchi/shimolinchi.github.io/master/img/2025-10-13-YOLO框架解读/yolov5.png)

yolov5架构如上图。
解释一下一些模块作用：

+ conv：就是卷积层
+ BN：Batch Normalization，批归一化

    计算均值与方差
    $$\mu=\frac{1}{m}\sum_ix_i, \ \sigma^2 = \frac{1}{m}\sum_i(s_i-\mu)^2$$
    归一化
    $$\hat{x_i} = \frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}$$
    线性变换（可学习参数）
    $$y_i = \gamma\hat{x_i}+\beta$$
    |功能|	效果|
    |---|---|
    |稳定训练过程|	减少梯度爆炸/消失|
    |加快收敛速度|	可以使用更大学习率|
    |提高泛化性能|	相当于一定的正则化效果|
    |平滑优化空间|	让损失曲面更平缓|
+ Leaky Relu: 为防止神经元死亡，将原本ReLu的负数部分改为一个小斜率$\alpha$，通常0.01到0.1
+ Res Unit: Residual Unit，残差单元

    如图所示，就是将原本学习输出改为学习残差。就是将该层从学习$y=F(x)$改为$y=F(x)+x$

    |优点|	说明|
    |---|---|
    |缓解梯度消失|	梯度可以通过 shortcut 直接传播|
    |提高收敛速度|	更容易训练深层网络
    |保留低层特征|	防止特征信息丢失
    |性能更强	|可以训练上百层的深度网络


# YOLO v8

![](https://raw.githubusercontent.com/shimolinchi/shimolinchi.github.io/master/img/2025-10-13-YOLO框架解读/yolov8.png)

解释一下经过卷积层之后的变化。可以看到主干backbone部分经过第一层卷积层之后图像大小从640*640*3变成了320*320*(64*w)。首先卷积层的参数有：
+ 卷积核大小k：即（k* k* 输入通道数）
+ 步长s：每隔几个像素卷一次，也就是卷一次移动几个像素
+ 填充p：卷积之前，在输入特征图的边缘周围添加额外的像素（通常是0）
+ 卷积核数：等于输出的通道数
+ 宽度乘子w：在不同模型中取不同的值，用于控制特征提取数量和模型大小。

下面解释一下其他参数和层

+ d是所谓的深度乘子，乘以6或3后变成n输入到c2f模块中，这个模块中的n确定Bottleneck的层数。

+ shotcut在c2f中可选要还是不要，就是选择是不是残差，即输出要不要加上输入本身

+ r是一个对于小模型的补偿比率，就是将模型的通道数给补偿回来。在前几层大模型得到了充分的特征提取，小模型没有。现在为了防止小模型过窄进行一个补偿。增加最终的表达能力

+ 上采样层（Upsample）就是将深层（分辨率更低）的给扩展一下分辨率，让其与浅层信息对齐然后进行拼接。上采样的方式有多种，如最近邻插值、双线性插值、反卷积、像素重排等
